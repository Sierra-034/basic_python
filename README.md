# Bases de Programación en Python

Colección de ejercicios de práctica para un curso introductorio de programación en Python, enfocado en estructuras de control: condicionales, ciclos `for`, ciclos `while`, `break`/`continue` y ciclos anidados.

## Estructura del repositorio

```
docs/     Enunciados de los ejercicios (especificación de cada problema)
src/      Espacio de trabajo del alumno: aquí van las soluciones (problema_01.py, etc.)
LICENSE   Licencia MIT
```

## Ejercicios

| # | Problema | Tema principal |
|---|----------|----------------|
| 1 | [El Clasificador de Tarifas](docs/problema_01.md) | Condicionales (`if`/`elif`/`else`) |
| 2 | [El Radar de la Avenida](docs/problema_02.md) | Ciclo `for` sobre listas |
| 3 | [El Cajero Automático](docs/problema_03.md) | Ciclo `while` con contador de intentos |
| 4 | [La Cinta Transportadora](docs/problema_04.md) | `continue` y `break` |
| 5 | [El Mapa de la Sala de Cine](docs/problema_05.md) | Ciclos `for` anidados |

## Cómo usar este material

Cada archivo dentro de `docs/` describe el contexto, las reglas de negocio, los requisitos y ejemplos esperados de un ejercicio. La tarea consiste en escribir, dentro de `src/`, un script de Python (por ejemplo `problema_01.py`) que resuelva el problema descrito, siguiendo las reglas y el formato de salida indicados en cada especificación.

Requiere **Python 3.8+**. No se necesitan librerías externas.
